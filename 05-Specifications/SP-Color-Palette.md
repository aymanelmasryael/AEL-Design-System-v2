**Version:** 1.0

**Owner:** AEL Digital Studio
**Governed By:** S-Color
**Classification:** Specification — Level 4

---

# 1. Purpose

This specification defines the official color palette for the AEL Design System.

It is the canonical source of all color values used across editorial, product, interfaces, and implementation platforms.
