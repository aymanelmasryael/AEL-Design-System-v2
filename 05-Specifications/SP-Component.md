# SP-Component — Component Specification

**Version:** 1.0
**Status:** Draft
**Owner:** AEL Digital Studio
**Governed By:** S-Component
**Classification:** Specification — Level 4

---

# 1. Purpose

This specification defines the required structure for every UI component in the AEL Design System.

---

# 2. Required Sections

Every component specification shall include:

- Purpose
- Anatomy
- Variants
- States
- Properties
- Behavior
- Accessibility
- Design Tokens
- Platform Mapping
- Usage Examples

---

# 3. Component Anatomy

Each component shall identify:

- Container
- Content
- Label
- Icon
- Supporting Elements

---

# 4. Variants

Components may define:

- Primary
- Secondary
- Tertiary
- Ghost
- Outline

---

# 5. States

Components may support:

- Default
- Hover
- Focus
- Active
- Disabled
- Loading
- Error
- Success

---

# 6. Accessibility

Every component shall define:

- Keyboard behavior
- Focus visibility
- Screen reader support
- Contrast requirements

---

# 7. Platform Mapping

Applicable to:

- HTML
- CSS
- SwiftUI
- Android
- Figma
- Canva
