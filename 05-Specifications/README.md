# 05 — Specifications

**Purpose:** Technical descriptions of specific entities, precise enough to be implemented without additional design decisions. Each specification describes exactly one entity.

**Scope:** One document per entity type (Button, Color Palette, Component, Grid, Icon, Illustration, Image, Spacing, Typography).

**Belongs here:** SP-Button.md, SP-Color-Palette.md, SP-Component.md, SP-Grid.md, SP-Icon.md, SP-Illustration.md, SP-Image.md, SP-Spacing.md, SP-Typography.md.

**Does NOT belong here:** Standards, registries, or implementation artifacts.
