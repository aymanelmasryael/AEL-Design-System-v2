# SP-Illustration — Illustration Specification

**Version:** 1.0  
**Status:** Draft  
**Owner:** AEL Digital Studio  
**Governed By:** S-Illustration  
**Classification:** Specification — Level 4

---

# 1. Purpose

This specification defines the implementation requirements for illustrations used throughout the AEL Design System.

---

# 2. Objectives

Illustrations shall:

- Enhance visual communication.
- Support storytelling.
- Reinforce brand identity.
- Improve user engagement.
- Maintain stylistic consistency.

---

# 3. Supported Formats

Canonical formats:

- SVG
- PNG
- WebP

SVG shall be the preferred source format.

---

# 4. Illustration Styles

Supported styles:

- Outline
- Flat
- Filled
- Isometric
- Minimal
- Abstract

Projects shall select one primary style for consistency.

---

# 5. Color Usage

Illustrations shall use Design Tokens.

Colors shall not be hardcoded except for approved brand assets.

---

# 6. Responsive Behavior

Illustrations shall:

- Scale proportionally.
- Preserve aspect ratio.
- Support responsive layouts.
- Remain legible at different sizes.

---

# 7. Accessibility

Illustrations shall:

- Include descriptive alternative text when informative.
- Be marked decorative when they convey no information.
- Maintain sufficient visual contrast.

---

# 8. Naming Convention

Examples:

hero-ai.svg

empty-state-search.svg

onboarding-step-01.svg

dashboard-analytics.svg

---

# 9. Platform Mapping

Supported for:

- HTML
- CSS
- React
- SwiftUI
- Flutter
- Figma
- Canva

---

# 10. Validation

Every illustration shall be validated for:

- Visual consistency
- Brand compliance
- Responsive scaling
- Accessibility
- File optimization
