# 01 — Ontology

**Purpose:** Defines the entities that constitute the AEL Design System and the permitted relationships between them. The model layer below Meta-Architecture and above all Standards.

**Scope:** Entity catalog, relationship matrix, exclusions list, authority flow.

**Belongs here:** The single Ontology document. Nothing else.

**Does NOT belong here:** Entity instances, specialized types, Standards, Specifications, or implementation.
