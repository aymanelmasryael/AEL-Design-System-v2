# AEL Brand Identity

**Official visual identity of the AEL Design System Platform.**

---

## Logo

| Variant | File | Usage |
|---------|------|-------|
| Primary | `06-Implementation/assets/logos/ael-logo.svg` | Default — light backgrounds |
| Primary — Dark | `06-Implementation/assets/logos/ael-logo-dark.svg` | Dark backgrounds |
| Icon Mark | `06-Implementation/assets/logos/ael-icon-mark.svg` | Favicons, app icons, social avatars |

## Safe Area

Maintain clear space equal to the logo's cap height on all sides. Do not place text, graphics, or other elements within this zone.

## Minimum Size

| Context | Minimum Width |
|---------|--------------|
| Digital (web) | 120px |
| Digital (mobile) | 80px |
| Print | 25mm |
| Favicon | 32px (icon mark only) |

## Brand Usage

- The AEL logo must not be modified, stretched, recolored, or distorted.
- The AEL logo must not be used in any context that implies endorsement without written permission.
- The icon mark may be used as a favicon or app icon without modification.
- Platform libraries must use the canonical logo from the Asset Registry — no platform-specific logo variants.
- Third-party use of AEL branding requires explicit written approval from the owner.
