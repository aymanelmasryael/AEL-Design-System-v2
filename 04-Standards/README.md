# 04 — Standards

**Purpose:** Rules that define what must exist within each domain: Foundations, Components, Assets, Templates, Documentation, Export, Archive. Standards answer "what" questions, never "how."

**Scope:** One document per domain standard.

**Belongs here:** S-Foundations.md, S-Components.md, S-Assets.md, S-Templates.md, S-Documentation.md, S-Export.md, S-Archive.md.

**Does NOT belong here:** Technical specifications, design tokens, implementation files.
