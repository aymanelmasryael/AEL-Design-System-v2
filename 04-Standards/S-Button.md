# S-Button — Button Standard

**Version:** 1.0  
**Status:** Draft  
**Owner:** AEL Digital Studio  
**Classification:** Standard — Level 3

---

# 1. Purpose

This standard defines the principles governing Button components within the AEL Design System.

Buttons are the primary interactive controls used to initiate user actions and shall provide consistent behavior, appearance, and accessibility across all platforms.

---

# 2. Objectives

- Ensure consistent interaction.
- Support accessibility.
- Promote component reusability.
- Enable cross-platform implementation.
- Maintain visual consistency.

---

# 3. Design Principles

Every button shall be:

- Clear
- Recognizable
- Accessible
- Responsive
- Predictable
- Theme-aware

---

# 4. Button Types

The design system supports:

- Primary
- Secondary
- Tertiary
- Outline
- Ghost
- Text
- Icon
- Icon + Label

---

# 5. Sizes

Standard sizes:

- Extra Small
- Small
- Medium
- Large
- Extra Large

---

# 6. States

Every button shall support:

- Default
- Hover
- Focus
- Pressed
- Active
- Disabled
- Loading

---

# 7. Behavior

Buttons shall:

- Respond immediately to user interaction.
- Provide visible focus indicators.
- Prevent duplicate submissions during loading.
- Maintain consistent animation timing.

---

# 8. Accessibility

Buttons shall:

- Support keyboard navigation.
- Include visible focus states.
- Meet WCAG 2.1 AA contrast requirements.
- Expose accessible labels for assistive technologies.

---

# 9. Design Tokens

Buttons shall consume:

- Color Tokens
- Typography Tokens
- Spacing Tokens
- Radius Tokens
- Shadow Tokens
- Motion Tokens

---

# 10. Cross-Platform Compatibility

Applicable to:

- HTML
- CSS
- React
- SwiftUI
- Android
- Flutter
- Figma
- Canva
