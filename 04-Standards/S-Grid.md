# S-Grid — Grid System Standard

**Version:** 1.0
**Status:** Draft
**Owner:** AEL Digital Studio
**Classification:** Standard — Level 3

---

# 1. Purpose

This standard defines the grid methodology used throughout the AEL Design System.

It establishes consistent alignment, spacing, and layout behavior across interfaces.

---

# 2. Objectives

- Improve alignment
- Increase consistency
- Enable responsive layouts
- Support reusable components
- Reduce layout complexity

---

# 3. Core Principles

- Consistent Alignment
- Modular Structure
- Responsive Layout
- Flexible Composition
- Predictable Behavior

---

# 4. Grid Model

The design system adopts a 12-column responsive grid.

Supporting layouts may use:

- 2 Columns
- 4 Columns
- 6 Columns
- 8 Columns
- 12 Columns

---

# 5. Layout Rules

Layouts shall maintain consistent:

- Columns
- Gutters
- Margins
- Alignment
- Baseline Rhythm

---

# 6. Responsive Breakpoints

- Mobile
- Tablet
- Laptop
- Desktop
- Large Display

---

# 7. Cross-Platform Compatibility

Applicable to:

- Mobile
- Desktop
- Print
- Canva
