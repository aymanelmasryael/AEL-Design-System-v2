# S-Typography — Typography Standard

**Version:** 1.0
**Status:** Draft
**Owner:** AEL Digital Studio
**Classification:** Standard — Level 3

---

# 1. Purpose

This standard defines the typography principles for the AEL Design System.

It establishes the rules governing type hierarchy, readability, consistency, accessibility, and cross-platform implementation.

---

# 2. Objectives

- Ensure visual consistency.
- Improve readability.
- Support multilingual typography.
- Maintain accessibility.
- Enable scalable design systems.

---

# 3. Typography Principles

- Readability First
- Consistency Over Decoration
- Clear Visual Hierarchy
- Responsive Scaling
- Accessibility by Default

---

# 4. Font Categories

- Display
- Heading
- Title
- Subtitle
- Body
- Caption
- Label
- Code

---

# 5. Hierarchy Rules

Typography shall establish information hierarchy using:

- Size
- Weight
- Contrast
- Spacing
- Alignment

---

# 6. Accessibility

Typography shall comply with WCAG recommendations for readability and contrast.

---

# 7. Cross-Platform Compatibility

This standard applies to:

- Web
- Mobile
- Desktop
- Print
- Canva
- Figma
