# S-Component — Component Standard

**Version:** 1.0
**Status:** Draft
**Owner:** AEL Digital Studio
**Classification:** Standard — Level 3

---

# 1. Purpose

This standard defines the universal principles governing all UI components within the AEL Design System.

It establishes a consistent methodology for designing, documenting, implementing, and maintaining reusable components across platforms.

---

# 2. Objectives

- Ensure consistency across all components.
- Promote reusability.
- Improve maintainability.
- Support accessibility.
- Enable cross-platform implementation.

---

# 3. Component Principles

Every component shall be:

- Reusable
- Modular
- Predictable
- Accessible
- Responsive
- Theme-aware
- Platform-independent

---

# 4. Component Anatomy

Each component shall define:

- Purpose
- Anatomy
- Variants
- States
- Properties (Props)
- Behaviors
- Accessibility
- Design Tokens
- Implementation Notes

---

# 5. Component States

Components may support:

- Default
- Hover
- Focus
- Active
- Pressed
- Selected
- Disabled
- Loading
- Error
- Success

---

# 6. Accessibility

Components shall comply with WCAG 2.1 AA requirements where applicable.

Keyboard navigation and screen reader compatibility shall be considered during implementation.

---

# 7. Cross-Platform Compatibility

Applicable to:

- Web
- Mobile
- Desktop
- Figma
- Canva
