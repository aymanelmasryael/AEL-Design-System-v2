# AEL API Reference

## Token API

**Endpoint:** `06-Implementation/platforms/json/tokens.json`

Flat JSON object with all 143 tokens. Each token includes id, value, type, category, and role.

## Component Registry

**Endpoint:** `07-Registry/component-registry.json`

All 37 components with metadata, token dependencies, states, variants, and platform mappings.

## Asset Registry

**Endpoint:** `07-Registry/asset-registry.json`

18 assets (15 icons + 3 logos) with source paths, variants, and platform support.

## CSS Variables

**Endpoint:** `06-Implementation/platforms/css/variables.css`

All tokens exported as CSS custom properties (`--ael-*`).
