# AEL Playground

The component playground will render any component with live token binding.

**Status:** Planned for v1.0 release.

## How it works

1. Select a component from the registry
2. Toggle variants, states, and sizes
3. All values are bound to SSOT tokens — generated CSS is hot-reloaded
4. Copy the HTML + CSS output directly

**Preview:** Open `06-Implementation/Components/Button/button.html` in a browser to see the Button component with all variants and states.
