# 06 — Implementation

**Purpose:** Concrete output files that implement Specifications. This is the only level that contains platform-specific formats.

**Scope:** JSON, CSS, SCSS, SVG, PNG, PDF, HTML, Canva assets.

**Belongs here:** colors.json, typography.json, variables.css, tokens.scss, icons/*.svg, etc.

**Does NOT belong here:** Specifications, Standards, or governance documents.
